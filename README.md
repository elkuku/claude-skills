# claude-skills

These are skills for [Claude Code](https://claude.com/claude-code).

| Skill | What it does |
|---|---|
| [ingress-mission-banner](ingress-mission-banner/SKILL.md) | Creates an Ingress mission banner from a folder of images, using IITC, Ultimate Mission Maker and the Mission Authoring Tool |

## Use

To make a skill available in every project, link it into your user skills folder:

```bash
ln -s ~/repos/claude-skills/ingress-mission-banner ~/.claude/skills/ingress-mission-banner
```
